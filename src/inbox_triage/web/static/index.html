Gmail triage, powered by Jev

Know what needs you. Let the rest wait.

Inbox Triage adds helpful Gmail labels (Needs You, Updates, For You, Later) using Jev by TypeSafe, on a schedule you choose. It never sends, deletes, archives, or marks anything read.
