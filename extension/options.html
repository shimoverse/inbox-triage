Inbox Triage

Shows label activity and recent senders and subjects in Gmail. It reads the Gmail tab title to select your account and asks your connected server to check for new mail; the server may add Inbox Triage labels. The extension stores a revocable server sign-in token, not your Google token or AI key. It does not read message bodies from Gmail's page.

To get started, sign in on your Inbox Triage server, then open Gmail for the same account and choose Connect Gmail in the bar.

Server address (self-hosting)

Use https, or http://127.0.0.1:8765 if you run Inbox Triage on this computer.

Connected Gmail accounts

    To connect an account, open Gmail and click Connect Gmail in the Inbox Triage bar.

    Disconnecting here removes this browser's server token and asks the server to revoke it when reachable. It does not disconnect Gmail from the server or remove existing labels; use the server's Settings to disconnect the Gmail account and delete its stored data.
